CodeSystem: Knowledge graph L1: predicates

Official URL: http://smart.who.int/base/CodeSystem/KGL1Predicates Version: 0.3.0
Active as of 2026-10-07 Computable Name: KGL1Predicates

The predicates of the L1 layer. An edge's predicate is one of these; which (source, target) pairs each licenses is the layer's edge table. Source: kg/src/L1.ts (migrated from smart-kg ontology/L1/L1.json).

This Code system is referenced in the content logical definition of the following value sets:

  • Knowledge graph L1: predicates

This case-sensitive code system http://smart.who.int/base/CodeSystem/KGL1Predicates defines the following codes:

CodeDefinition
contains Layout containment only: publication, sections, elements. It never points at content.
hasSupplement A guideline to its web annex or supplementary document (handbook §12.1).
supersedes This replaces that, between publications and between individual recommendations (handbook 1.7.2, 1.7.2,
refines A recommendation narrows or conditions another.
partOf A sub-recommendation a), b) to its parent. Each part carries its own change status (HIV SI 2022).
definedIn The one publication that issued this content: its authority.
presentedIn A place this content is printed, in any publication. Many per node. Restatement is presentedIn into a publication other than definedIn. The edge carries renderedText only when the printed wording differs from the stored text.
answers A recommendation answers a key question. Many-to-many (handbook §7.4).
addresses A row of an evidence profile addresses a key question.
hasOutcome A key question names an outcome. A list shared by several questions is one set of outcome nodes.
forOutcome An evidence row grades one outcome. Optional: qualitative evidence may concern a criterion such as values.
aboutIntervention The I of a key question, joined to a catalogued intervention.
supportedBy A recommendation to the evidence it rests on.
hasRemark A recommendation to a remark: definition, implementation, precaution, contraindication, subgroup, research gap or training.
recommends A recommendation concerns a catalogued intervention. Optional: only when the mapping is known.
measures What an indicator counts: a catalogued intervention, or adherence to a recommendation (handbook Table 10.2).
justifiedBy Why an indicator exists: the recommendation its rationale cites (HIV SI 2022, PRV.3).
crossReferences Names an external code. Records that a code was cited, never what it means. Terminology is a leaf.
classifiedAs Placement of a catalogued intervention in UHC, ICHI or CDHI.
numberedAs A citation's '(n)' to row n of the same artefact's reference list. Mechanical.
resolvesTo What a citation or reference entry refers to, as precisely as the string allows. Matching is a judgement: inferred, or decided when a person chose between candidates.
